# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：
    素のLLM（第1回）は自身の事前知識のみで回答するため、一般的な定義には答えられますが、AIE2026講座固有のニュアンス（例：「3レベル」の具体的な定義）は正確に答えられず、ハルシネーションを起こす可能性があります。一方、エージェントは回答を生成する前にツール（`search_glossary`）を呼び出して講座の用語集を検索し、事実に即した正確な情報を提供します。また、指示通り回答の最後に「（関連：第2回）」と出典元を明示する点も異なります。
- `--trace` で見えたツール呼び出し（ツール名と引数）：
  - 修正前： `search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})` （別々に2回呼び出し）
  - 修正後： `search_glossary({'query': 'LoRA, QLoRA'})` （カンマ区切りの引数でまとめて1回呼び出し）
  - クイズ出題時： `make_quiz({'lecture': 2})`
- 1つの質問での LLM 呼び出し回数（`requests`）：
   出力された `[usage]` ログの通り、1つの質問に対するLLMの呼び出し回数（requests）は 2回でした（初回プロンプトでのツール呼び出し要求で1回、ツールの返り値を受けた最終的な回答生成で1回）。
- 追加したツールと、docstring に書いた説明：
   `make_quiz`
   指定した回の用語から1つを選び、確認問題と答えを返す。
  「第2回の確認問題を出して」のように、復習用の問題を求められたときに使う。
